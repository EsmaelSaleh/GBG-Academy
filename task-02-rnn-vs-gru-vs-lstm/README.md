# Task 2: RNN vs GRU vs LSTM Comparison

This practical task compares the performance, architecture, and behavior of basic RNNs, GRUs, and LSTMs on sequence modeling tasks.

## Structure
- **`notebooks/`**: Contains the main Jupyter notebook `RNN_vs_GRU_vs_LSTM.ipynb` demonstrating the training and comparison of the models.
- **`plots/`**: Contains loss and accuracy plots generated during training to visually compare the models.
- **`docs/`**: Contains the detailed report explaining the differences, strengths, and weaknesses of each architecture based on the experiments.
