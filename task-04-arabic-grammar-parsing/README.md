# Task 04: Arabic Grammar Parsing

This directory contains the fourth task focusing on Prompt Engineering for Arabic Grammar Parsing (الإعراب). 

## Directory Structure
- `docs/`: Contains task documentation, the Prompt Engineering assignment requirements PDF, and a detailed breakdown of the prompt engineering journey and results.
- `notebooks/`: Contains the Jupyter notebook implementation of the Arabic grammar parser using the `inceptionai/jais-family-6p7b-chat` model.

## Documentation
Please read the [Arabic Grammar Parsing Journey](docs/Arabic_Grammar_Parsing_Journey.md) for a complete explanation of the prompts used, the setup, and a comparison of the results between the baseline and engineered prompts.
