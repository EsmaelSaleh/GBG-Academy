# Task 1: Arabic Text Correction

This task focuses on building an Arabic text correction pipeline. 

## Structure
- **`data/`**: Contains the datasets used for training and testing.
- **`notebooks/`**: Contains Jupyter notebooks detailing the data exploration, model training, and text correction pipeline.
- **`docs/`**: Contains reports and documentation detailing the Arabic correction journey.
- **`scripts/`**: Contains utility Python scripts.

## How to use
1. Clone the repository.
2. Ensure you have the required dataset `ar_50k.txt` placed in the `data/` folder (not included in the repository due to size).
3. Open the notebooks in the `notebooks/` directory to follow the experiments and the final models.
