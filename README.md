# GBG Academy AI Diploma

Welcome to my repository for the GBG Academy AI Diploma! This repository contains my practical tasks and projects completed during the diploma.

## Repository Structure

- [**`task-01-arabic-text-correction`**](./task-01-arabic-text-correction): A project focused on correcting Arabic text using NLP techniques.
- [**`task-02-rnn-vs-gru-vs-lstm`**](./task-02-rnn-vs-gru-vs-lstm): A comparative analysis of RNN, GRU, and LSTM models.
- [**`task-03-transformers-encoder-decoder`**](./task-03-transformers-encoder-decoder): Full documentation and explanation of Transformers, Encoder, and Decoder architectures.
- [**`task-04-arabic-grammar-parsing`**](./task-04-arabic-grammar-parsing): Prompt engineering task focusing on complex grammatical parsing (الإعراب) of Arabic sentences.

## Tasks Overview

### Task 1: Arabic Text Correction
In this task, we built models and pipelines for Arabic text correction. The task includes processing large text data and building a robust correction system.
*Read more in the [Task 1 README](./task-01-arabic-text-correction/README.md)*

### Task 2: RNN vs GRU vs LSTM
This task is an in-depth comparison of Recurrent Neural Networks (RNN), Gated Recurrent Units (GRU), and Long Short-Term Memory (LSTM) networks on sequential data, exploring their architectures, performance, and convergence.
*Read more in the [Task 2 README](./task-02-rnn-vs-gru-vs-lstm/README.md)*

### Task 3: Transformers, Encoder, and Decoder
This task provides a complete guide to the Transformer architecture, explaining the self-attention mechanism, the Encoder, the Decoder, and the different architecture families (Encoder-only, Decoder-only, Encoder-Decoder).
*Read more in the [Task 3 README](./task-03-transformers-encoder-decoder/README.md)*

### Task 4: Arabic Grammar Parsing
In this task, we explored prompt engineering for the Arabic language, specifically focusing on complex grammatical parsing (الإعراب) using the `jais-family-6p7b-chat` model. We analyzed how strict constraints, roles, and context improve structured output accuracy compared to baseline generic prompts.
*Read more in the [Task 4 README](./task-04-arabic-grammar-parsing/README.md)*
